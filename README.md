# JokerCrafting

Every Joker you find in Balatro is a Common. To get anything better, craft it: two Jokers of the same rarity become one of the next rarity up.

## How it works

| Ingredients | Result |
|---|---|
| Common + Common | Pick 1 of 3 Uncommon Jokers |
| Uncommon + Uncommon | Pick 1 of 3 Rare Jokers |
| Rare + Rare | Pick 1 of 3 Legendary Jokers |

**To craft,** drag a Joker down off your Joker row and drop it on another Joker of the same rarity. While you hold it, a label above the card tells you what the drop would do. Dragging sideways still just reorders your Jokers.

A Craft? screen shows both Jokers and what they make. Back costs nothing. Craft opens a pick screen with three Jokers of the next rarity. Choose one and both ingredients are used up. There is no going back from the pick screen.

**Every Joker the game gives you is a Common.** That covers the shop, Buffoon Packs, Judgement, Wraith, The Soul, Riff-raff, and the Uncommon and Rare Tags. Crafting is the only way to climb.

## Rules

- Crafting is free.
- You can craft in the shop, at blind select, between hands during a round, and while a pack is open. Making room in a full Joker row before taking a Joker from a Buffoon Pack works.
- Editions carry over. If one ingredient has an edition, the crafted Joker gets it. If both have different editions, you choose which one. A Negative edition keeps its free slot.
- Legendary Jokers are the top tier and cannot be crafted further. Eternal Jokers cannot be used as ingredients.
- You are never offered a Joker you already own, unless you have Showman. If fewer than three Jokers of the next rarity are left, you get what is left.
- Crafting a Joker away works like selling it: anything that Joker was doing stops right away.
- Ankh and Invisible Joker still work, and can copy a crafted Joker.
- The offers follow the run's seed, so the same seed and the same crafts give the same offers.

## Installation

Requires Steamodded. Tested against 1.0.0~BETA-1620a.

Place the folder in your Balatro mods directory:

```
Balatro/
  Mods/
    JokerCrafting/
      JokerCrafting.json
      JokerCrafting.lua
```

## Settings

Under Mods, Joker Crafting, Config.

| Setting | Default | What it does |
|---|---|---|
| Enable Joker Crafting | On | The whole mod |
| Commons only | On | Every Joker the game gives you is a Common. Turn off to keep normal rarities |
| Crafting table look | On | Shows the Craft? screen as Joker + Joker = ?. Off shows a plainer layout |
| Test mode | Off | For trying things out. Left Ctrl + 1, 2 or 3 adds two random Commons, Uncommons or Rares. Left Ctrl + E changes the edition of your rightmost Joker. Left Ctrl + J adds a Joker slot |

## Compatibility

Works alongside HandyBalatro and JokerDisplay. Mods that also change which rarity of Joker the game rolls, or that filter which Jokers can appear, may conflict with the Commons only rule or with the crafting offers. Mods that only add Jokers, consumables, vouchers or decks should be fine; their Jokers can be crafted like any other as long as they use the standard rarities.
